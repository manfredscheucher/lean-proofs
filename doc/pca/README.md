# Arrangements of pseudocircles

* `model.md`: the dart model shared by all libraries below (σ, α, cells, axioms, sides, flips).
* `pca.md`: `Pca`, counting, digon and fan lemmas, the upper and lower bounds on triangles.
* `sweep.md`: `PcaSweep`, the Snoeyink–Hershberger sweeping lemma.
* `great.md`: `PcaGreat`, great-pseudocircle arrangements, Ringel's theorem, Levi's lemmas.
* `flipgraph.md`: `PcaFlipGraph`, triangle flip connectivity of intersecting arrangements.
* `circ.md`: `PcaCirc`, circularizability (in progress).
* `noncirc.md`: `NonCirc`, non-circularizability certificates (in progress).

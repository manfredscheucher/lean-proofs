# Documentation

One page per library: what is proved, the main Lean declarations, axioms, sources, and where the
formal proof deviates from the paper.

* `pca/`: arrangements of pseudocircles (libraries `Pca`, `PcaSweep`, `PcaGreat`, `PcaFlipGraph`,
  `PcaCirc`, `NonCirc`).
* `kholes/`: k-holes in random point sets (library `KHoles`).
